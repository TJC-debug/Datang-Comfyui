# 证件照排版隐藏参数兼容修复

日期：2026-10-11。正式源码 Datang-Comfyui 0.4.58；PS_AI、纳贝工作台和 Photoshop 插件未修改。

用户提供的“01证件照快速排版.json”中，节点 19 DatangIdPhotoLayout 的 widgets_values 为 [300, null]；用户同时确认“高级：查看当前排版数据”为空。后端声明“排版数据”为必填 STRING，因此这份文件没有完整执行布局。不能根据部分截图恢复全部作者参数。

旧前端隐藏控件使用对象展开复制原生控件。现代 ComfyUI DOM 控件的 name、type、options 可以来自原型访问器，value 还可能是不可配置访问器，且 DOM 注册保留原对象。复制会丢失继承名称和注册身份。按照官方 graphToPrompt 的控件扫描规则，无 name 的控件不会进入 API 输入。在原型名称、不可配置 value 的模拟原生 DOM 控件上已复现“面板写值但 API 缺少排版数据”；这证明本地代码存在该兼容缺陷，不代表已直接读取 RunningHub 当前安装的源码。

修复保留原生控件对象、名称、类型、值访问器与 DOM 注册，内部 UI 写值和原回调只执行一次；配置完成后根据恢复的真实值同步面板。空值和无法识别的数据清空陈旧预览并提供重新确认指引，外部轮询不会静默替换缺失布局。用户重新选择预设或调整参数后，工作流保存与 API 提交使用同一份实际布局。有效外部冻结布局在重载、轮询和提交后逐字保留。后端的必填输入、布局校验与图像算法没有放宽。
