# 证件照排版隐藏参数兼容说明

适用版本：Datang-Comfyui 0.4.58。

## 修复的问题

部分 ComfyUI 前端使用原生 DOM 控件，其名称和选项来自原型访问器。旧隐藏控件逻辑复制控件对象，可能丢失名称和注册身份，导致排版面板看似正常，但 API 提交缺少必填的“排版数据”。

新版本保留原生控件对象及其名称、值访问器、选项和注册身份。内部写值与原回调只执行一次；工作流加载完成后，面板按恢复的实际数据更新。有效的冻结布局在保存、重载和提交过程中保留。

缺失或无效的数据会清空陈旧预览并显示重新确认指引。后台轮询不会静默套用默认布局。后端必填输入、布局校验及图像算法保持原有规则。

## 更新与操作

1. 更新完整仓库，确保存在新增的 `web/id_photo_layout_widgets.js`。只替换主脚本会造成模块加载失败。
2. 重启 ComfyUI 或平台对应节点环境，刷新工作流页面。
3. 若旧工作流的排版数据为空，重新选择所需的快捷排版，或确认纸张、证件照尺寸、方向及 DPI 等参数。没有保存的布局无法自动还原。
4. 展开“高级：查看当前排版数据”，确认有完整 JSON，运行后保存工作流。
5. 重新打开并再次运行；API JSON 中该节点的 `inputs.排版数据` 应包含实际布局字符串，`inputs.DPI` 应为当前选择值。
